# 3D Jelly Physics 1.9.3 — PhysikX

Application version **1.9.3**, mobile build **193**, release tag **v1.9.3-physikx**.
Native PhysikX 0.2.0-beta.1 predicts every jelly node. The Jelly extension retains
1.9.3 tetrahedral elasticity, volume/inversion protection, recovery and rigid fitting.
The host couples contacts and mouse/touch grabbing to the extension.

Android: development-signed ARM64/x86_64 APK; changing the test certificate may
require uninstalling the old app and clears settings. iPad: unsigned arm64 device
IPA; Apple signing/provisioning are required. The application version is unchanged.
Desktop packages are also included. PhysikX license and MIT Jelly notices are bundled.
Real-device performance and calibrated gel material behavior are not claimed.
